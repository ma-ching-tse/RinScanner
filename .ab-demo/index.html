RinScanner A/B — 同一设计,两份出码,渲染对比

左 = A(乱稿出码):颜色写死 hex、布局绝对定位。  右 = B(整理后出码):颜色 var(--color-bm-*) token、布局 flex。
两份都是 Figma MCP 真实生成的代码,这里按其语义如实渲染。静态浅色下故意做到一样——区别在真实工程条件下才暴露。
TOKEN 轴 → 看「深色主题」行 布局轴 → 看「长文案 / i18n」行 A 乱版 B 干净版
① 浅色主题(基准)
两份代码渲染一致 —— 证明 A/B 内容、视觉完全相同,对比是公平的。
② 深色主题(切一下主题就见真章)
同样的页面,把设计系统切到深色。B 的 token 自动跟随;A 写死的 hex 纹丝不动 —— 深色背景里一张刺眼白卡,文字配色全错。
③ 长文案 / i18n(浅色,文案变长)
同一处文字换成更长的德语翻译。B 的 flex 自动重排;A 的绝对定位 + 固定偏移 → 文字直接重叠。
